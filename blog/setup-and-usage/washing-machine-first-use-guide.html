Washing machine first-use guide: from completed installation to your first laundry load

Start ordinary laundry only after the installation and the model’s required first-use preparation are complete. Check your exact instructions for an initial programme, any permitted product and calibration where applicable. There is no universal first-wash temperature, detergent quantity or button sequence for every washer.

This guide helps you establish what the installer completed, what remains for you and how to choose the first ordinary load. It applies to a newly installed automatic washer; a machine returned from storage or recently moved also needs its condition and installation reviewed before use.

Installed with a documented first-use task still pendingFollow that model’s task only after readiness is confirmed.
Preparation complete and no unresolved issueChoose an ordinary suitable load and programme.

Used appliance with an uncertain historyEstablish the condition and setup first; do not assume it is equivalent to a new machine.

An app connection or an illuminated display does not establish that water supply, drainage and physical setup have been completed correctly. Ask about each relevant part of the handover rather than using one successful screen response as proof of readiness.

Six stages for the first ordinary wash

  1. Confirm the installation handover

    Ask what the installer prepared, connected and checked. Identify any unfinished work or model-specific task still required. Do not run laundry while the transport preparation, supply arrangement or installation status remains uncertain.

  2. Read the correct first-use instructions

    Use the exact manual, not a programme name remembered from an earlier washer. Establish whether the instructions require an empty programme, a specified product, calibration or another step. If the installer already completed a task, record that instead of automatically repeating it.

  3. Set up normal controls and product delivery

    Understand the chosen programme, start/pause control and permitted cancellation method. Identify the detergent route and any automatic-dosing setup. Keep a manual dose from accidentally duplicating automatic dispensing.

  4. Choose an uncomplicated suitable load

    Follow garment-care labels and the programme’s dry-load limit. Use a normal compatible load that you can evaluate, rather than beginning with a bulky specialist item or combining several uncertain fabrics. Do not exceed the limit to test the advertised capacity.

  5. Observe normal operation from a safe position

    Stay available during the first use to notice an obvious leak, outlet overflow, unusual movement or error. Do not open panels, reach underneath or interfere with a moving machine. Stop and obtain help when a significant abnormal condition appears.

  6. Review the completed result and begin the care routine

    Unload through the permitted access method and check the outcome. Keep the programme and product information if a question remains. Use the model’s after-use care and safe ventilation arrangements, then store the instructions with your installation record.

Ask the installer to name the completed task. “Demo done” can mean a control explanation, a calibration sequence or an operating check; those are not interchangeable records. A short precise note prevents you from repeating the wrong procedure.

Should you run the machine empty before using it?

Check the first-use section for the actual model. Samsung India provides a first-time-use procedure for the machines covered by its guidance, but a regional support example is not a universal programme recipe. Your manual determines whether an initial cycle is required and exactly what belongs in it.

Do not assume that Drum Clean, Cotton, Quick Wash and a test cycle are equivalent. Their purposes and conditions can differ. If the manual names a particular procedure, use that instruction rather than choosing the hottest or longest available setting.

The same applies to products. An initial preparation step may have a different instruction from routine laundry or later maintenance. Do not add detergent, descaler, bleach or a home mixture merely because a different machine’s tutorial uses one.

If your manual is unclear, ask manufacturer support to identify the correct first-use section. A missing instruction is a question to resolve, not an invitation to create an aggressive cleaning recipe. Keep the answer with the model record for future reference.

Calibration is model-specific and has a defined purpose

Samsung India’s calibration guidance describes an empty-drum procedure for applicable machines after installation or movement and warns that control layouts differ. This is useful evidence that some washers have a setup task beyond simply pressing Start. It does not mean every brand uses that function.

Find the relevant procedure for your model before entering any button combination. Do not try a sequence from another control panel until a display changes. Service menus and ordinary owner setup should not be confused.

If calibration has already been completed as part of the documented handover, you do not need to repeat it for reassurance without a reason. If it fails or a message returns, record the outcome and seek the appropriate guidance.

Calibration cannot correct a damaged hose, a blocked household drain or a machine installed with unresolved transport preparation. Physical readiness comes first. A successful setup message should not override visible leakage or unsafe movement.

Prepare the first dose before filling the compartment

Read the washer requirements and current detergent label. Identify the appropriate compartment or permitted delivery route, and check any removable insert or automatic reservoir instructions. A familiar brand name does not establish the correct dose for a new system.

A new washer is a good opportunity to replace “one unmarked cap” with a measured routine. Record the exact product, applicable dose and programme so another household member can repeat the same use. Do not treat a compartment’s maximum line as the recommended amount for every load.

Where automatic dosing is fitted, establish what the reservoir accepts and how manual dosing is selected when needed. Do not fill reservoirs with guessed mixtures or add extra product to the drum because the first wash should be “extra clean.”

For a fuller selection framework, see choosing suitable detergent. Keep that laundry decision separate from any product instruction for the model’s initial empty programme.

Choose a load that gives a clear first-use result

Start with garments whose care requirements you understand and a programme that matches them. A mixed basket containing a duvet, delicate garment and ordinary cottons makes it harder to judge whether an unsatisfactory result comes from the load choice or the machine.

Use the programme’s own load limit. The largest kilogram capacity advertised for the appliance does not automatically apply to quick, delicate or specialist programmes. Avoid forcing clothes into the drum as a test of value for money.

If the household needs to wash a specialist item first, read the relevant garment and appliance guidance carefully. There is no requirement to use an unsuitable ordinary cycle simply because it is the first wash.

Record the selected options if there is a question later. Wet laundry after a deliberately reduced or omitted spin is different from a machine that could not complete its intended spin. The programme and options help make the enquiry specific.

Observe the cycle without trying to diagnose it internally

A washer can pause, change its time estimate or show little visible water as part of its normal design. Use the manual to interpret the model’s status. A timer change alone does not justify opening the machine or repeatedly cancelling the cycle.

An obvious external leak, household outlet overflow, strong burning smell, repeated electrical trip or violent movement is a different matter. Stop operation and obtain appropriate help; keep clear of wet electrical areas and do not hold the cabinet through a spin.

Do not create repeated demonstrations of a dangerous condition for a video. An existing photograph, the displayed message and a description of the stage can be enough to begin the service conversation.

Use problems after installation if the first use does not proceed normally. The timing is useful evidence, but it does not prove whether the cause belongs to installation, the property or the appliance.

You do not need a diary of every successful wash. Keep enough information to avoid repeating uncertainty and to explain a problem if it occurs. A clear first-use note also helps a new household user learn the machine without relying on several conflicting instructions.

Three first-use questions with different answers

The delivery team placed the washer but did not connect it

Complete the installation first. A new machine is not ready just because it is unpacked and its controls light up.

The installer confirms the model’s initial preparation was completed

Record that task and move to the appropriate ordinary-use instructions. Do not automatically run another chemical clean.

The first laundry cycle produces a leak near the waste outlet

Stop the cycle safely and report the location and stage. Do not keep retrying different programmes to see whether one avoids the problem.

Booking, visiting and inspection charges

The visiting charge is ₹200 if no repair is carried out. Inspection charges depend on location. Share your Bangalore locality or PIN code and confirm all applicable charges together before booking. ₹200 is not an advertised complete repair or parts-replacement price.

Ask how the visiting and inspection charges are treated if a repair proceeds. No automatic waiver, deduction or additional charge should be assumed. Your approved quote should make clear whether these amounts are included, credited or payable separately, and state any applicable tax and the final payable total.

For an installation-only, disconnection or reinstallation enquiry, confirm the applicable booking and cancellation terms specifically. The no-repair visiting rule is not a complete installation price, and it should not be used to assume how a different service is charged.

Understand the installation and supplied-part terms

New parts supplied by FixMyWasher carry a one-year warranty. Ask for the supplied part to be identified on your job record or invoice. This applies to that new part; it does not turn the job into a one-year warranty on the entire washing machine.

Repairing an existing component is different from supplying a new one. Confirm the terms for repaired boards, retained parts, workmanship, labour, revisits and customer-supplied items separately. Do not infer those terms from the new-parts warranty.

Keep the quote, approved changes and completion record together. If the symptom returns, report what happened and when rather than assuming that the same part has failed. Stop using the washer if it leaks significantly, trips the circuit or develops a burning smell.

Installation labour, adjustments and a setup check without a supplied new part do not create a one-year whole-machine warranty. Confirm workmanship and revisit terms separately. Check any installation included with a new purchase before arranging independent work; FixMyWasher does not claim manufacturer-authorised status.

Frequently asked questions

Must every new washer run empty first?

Check the exact model’s first-use procedure. Do not apply one programme or product instruction to every appliance.

Should I use the hottest programme for the first wash?

Only use the procedure specified for your model. The hottest setting is not a universal preparation method.

Is calibration the same as drum cleaning?

No. Calibration and cleaning have different purposes. Use each only where the model instructions require it.

Can I copy a calibration button sequence from another model?

No. Match the control layout and procedure to your actual model.

What if the installer already ran a test?

Ask which test or preparation task was completed and whether anything remains. A vague “demo” description is insufficient to decide.

Can I fill the detergent drawer to MAX?

The maximum line is a limit, not a universal dose. Use the current product and appliance instructions for the load.

Should I start with a full bedding load?

Only if the item and programme requirements are met. An uncomplicated suitable load is usually easier to evaluate when learning the controls.

Does a changing timer prove a fault?

Not by itself. Interpret the actual status using the model instructions and assess any accompanying failure or unsafe symptom.

What if the washer shakes severely on first use?

Stop operation safely and request assessment. Do not hold it down or repeat unsafe spins for a recording.

Does one successful cycle guarantee the entire washer?

No. It records that completed use, not a comprehensive guarantee of every future programme or component.
